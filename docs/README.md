The illustrated algorithm reference retains its 2.13-era worked examples and
links to later versioned changes. Use the current architecture and source for
current behavior, especially adaptive terrain, snapshot ownership and salinity.

Editable illustrations are in [`illustrations/`](illustrations/). Measurements
and rendered comparisons are in [`observations/`](observations/); they retain
their original scope and machine-specific timing context. Generation recipes
are in [`../examples/`](../examples/).

The 2.14–2.28 revision archive covers adaptive landscapes, browser snapshots,
fixed rendering, fantasy styles, automatic feature refinement and salt budgets.
Machine-specific numerical/browser reports live under
[`observations/measurements/`](observations/measurements/).

The repository keeps one illustrated algorithm reference. Duplicate architecture
copies, embedded copies of the same diagrams, packaged source snapshots and
unrelated planning templates are omitted.

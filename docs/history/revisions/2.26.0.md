# Atlas 2.26.0 — regional refinement and quiet-land simplification

Final automatic detail passes now identify broad lake districts and can remove
unnecessary cells from quiet grassland and forest interiors. The existing local
shore, river, coastline and terrain-curvature detectors remain active.

## Regional selection

Lake districts use physical, seasonal lake coverage and shore boundaries rather
than blue map colors or biome labels. Area-weighted neighborhoods collect shore
evidence over a configurable geographic radius. Several occupied geographic bins
must contribute; one isolated lake remains a local feature. Three-dimensional
spherical bins handle the date line and poles without special latitude seams.

Selected districts receive continuous refinement caps, including dry land between
small lakes. The detector can supply a geographic radius through the shared
`FeatureDetector` interface; future regional detectors can use the same planner.
Half the estimated insertion budget is reserved among active detectors, with a
configurable district weight. The remaining half follows combined importance.
Fine features inside a district can still request smaller cells. A district too
large for the available budget is reduced to a useful continuous footprint.

## Quiet land

Before each final refinement pass, simplification considers coherent grassland,
savanna, Mediterranean and forest interiors. It protects water, shorelines,
channels, lake outlets, deltas, oxbows, wetlands, biome boundaries, sharp relief
and detected lake districts. A neighbor ring preserves the complete triangle
neighborhood of each protected feature.

Eligible nonadjacent sites are removed and their local cavities retriangulated.
Retained coordinates stay exact. Each removal must satisfy the configured spacing
limit and a reconstructed-height error check across the affected terrain. This
is actual mesh simplification, including original base cells, not display LOD.
Cell IDs are compacted; geographic anchors remain valid.

Terrain transfers preserve sediment mass. Transfers, water routing and channels
are rebuilt after each changed mesh. Climate forcing and elapsed landscape time
stay fixed. Final river courses, deltas, ecology and resources use the final mesh.

## Controls

Under **World parameters → Automatic feature detail**, the existing final-pass,
target-spacing and extra-cell-budget controls are joined by:

| Control                     | Fresh-world default | Effect                                                                                   |
| --------------------------- | ------------------- | ---------------------------------------------------------------------------------------- |
| Lake district detail        | 60%                 | District priority in the reserved insertion budget; zero disables the regional detector. |
| District search radius      | 300 km              | Neighborhood used to group scattered lakes into broad regions.                           |
| District shore evidence     | 5%                  | Minimum area-weighted shore signal; lower values include sparser districts.              |
| Quiet-land reduction budget | 10%                 | Maximum total removals, measured against the mesh before final passes.                   |
| Quiet-land maximum spacing  | 250 km              | Upper covering-spacing limit for replacement triangles.                                  |
| Quiet-land height tolerance | 25 m                | Maximum sampled reconstruction error allowed for a removal.                              |

The insertion and removal limits are independent and shared across all final
passes. Removing cells never increases the allowed number of insertions. Limits
are ceilings, not targets: protected or complex terrain can leave most of a
removal budget unused. The global cell count can still grow while quiet regions
become coarser.

Quick preview disables these final passes. Balanced cloud enables the settings
above with 40,962 base terrain and weather cells. Legacy recipes and saved worlds
default the new district and removal controls to zero. Exact removal selections
and refinement caps are saved in recipes with source-mesh and configuration
signatures. Invalid or mismatched plans fail explicitly. Manual regional
refinement does not trigger another automatic global pass; saving stays manual.

## Cell grid

Land edges use a darker, thicker screen-space stroke. Water edges retain their
lighter appearance. Grid geometry continues to follow relief, and flat-map seam
and pole handling remains in place.

## Validation

See `scripts/measure-auto-regions.ts` and the accompanying measured report for
the AETHER-2408 comparison. The fixture recreates the seed and reference settings;
it is not the user's exact saved snapshot.

The recreated Balanced cloud run uses 40,962 base terrain cells and 40,962
weather cells. Earlier adaptive passes produce 251,559 surface cells; final
adaptation removes 799 and inserts 30,633, ending at 281,393. These remain below
the independent 25,155 removal and 50,311 insertion limits.

In the selected 300 km lake district near 30.59° N, 70.06° E, the surface grows
from 165 to 954 cells. Median area-equivalent spacing falls from 44.27 to
17.67 km. A quiet 150 km grassland interior near 41.58° N, 11.61° E falls from
42 to 28 cells, while median spacing grows from 44.02 to 52.33 km. Its surrounding
features remain finer. The protected river comparison retains its original grid.

Retained array buffers increase from 228.08 to 251.85 MiB because this run adds
more detail than it removes. Full synchronous generation takes 112.2 seconds in
one observation; this is not a browser multithreading comparison. The global
water-ledger relative residual is below 4e-14. Benchmark snapshots are temporary
QA artifacts and do not save or modify the user's world.

Quiet-land candidate staging uses typed arrays and discards unselected cavity
geometry. A 40,962-cell one-removal check preserves identical geometry and order
while keeping its intermediate candidate storage linear and compact.

All 497 tests pass, including generated multi-pass deletion/insertion, exact
recipe replay, async parity, conservation, protected feature neighborhoods,
old-recipe defaults and invalid-plan rejection. Whole-project TypeScript checks
pass. Browser control checks confirm all six new controls work and editing them
neither generates nor saves a world.

The land grid uses 2.2-pixel strokes, water 1-pixel strokes, and one ordinary
triangle draw per existing batch. Packed endpoint textures share canonical globe
buffers. The 40,962-cell isolated grid benchmark retains 15 draw calls; added
retained CPU/GPU storage is about 1.27 MiB for a flat map or 0.57 MiB for a globe.
Wider lines have a cost: the software-rendered cloud test, including synchronous
pixel readback, takes about 2.3 times the old thin-grid raster time. This is not a
full-world frame-rate measurement. See [grid measurements](../../observations/measurements/land-grid-2.26.0.json).

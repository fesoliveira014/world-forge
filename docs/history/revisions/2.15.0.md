# World Forge 2.15.0 — Evolving adaptive landscapes and parallel seasons

Recent landscape evolution runs in time steps with refreshed drainage. River,
hillslope and wind transport move material; optional remeshing transfers existing
bedrock, sediment and erosion histories rather than restarting the landscape.
Fine volcanic detail uses retained source history and construction budgets.

Independent climate seasons can execute on up to four workers, with fixed result
assembly preserving numerical parity. Quality presets select detail settings
without changing the seed or physical parameters.

See [adaptive landscapes](../design/adaptive-surface.md), the
[cloud calibration](../design/cloud-performance.md), and
[AETHER-EVOLVED.json](../../../examples/AETHER-EVOLVED.json). Timing and memory
observations refer to their recorded hardware and version.

This summary records the imported prototype milestone; current behavior is
documented in the [architecture](../../architecture.md).

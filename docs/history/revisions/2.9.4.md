# v2.9.4 — readable source

The cleanup makes the existing implementation easier to follow without changing its world-generation parameters or numerical algorithms. Generator identity remains **2.9.0**.

## Changes

- Expanded grouped declarations and compressed conditionals into separate statements and braced blocks throughout the authored application, generation, and rendering code.
- Replaced ambiguous local aliases with names describing cells, corners, receivers, seasonal fields, plate frames, transport budgets, and mesh offsets. Renamed helpers such as `computeStableTimeStep`, `collectWorldBuffers`, `getCoursePoints`, and `addBevelTriangle`.
- Moved cell and overlay construction into `WorldMeshes.ts`, leaving camera, interaction, and scene lifecycle in `WorldView.tsx`.
- Added a shared typed worker-message contract in `generation-messages.ts`.
- Expanded shaders into readable GLSL with descriptive names and preserved formulas.
- Documented packed-array layouts and units. Added [a source guide and coding conventions](../../development.md), complete formatting commands, editor defaults, and simple declaration/bracing rules.

Snapshot field names, project imports, generator defaults, thresholds, seed streams, and the accepted lake/river/bank/delta rendering remain compatible. No runtime dependency was added.

## Focused verification

A small AETHER-0003 generation (surface level 5, process level 4) produced exactly matching SHA-256 fingerprints of its numerical fields and metadata before and after cleanup, excluding elapsed time and stage timings. On the retained AETHER-0004 snapshot, every river vertex/index/attribute buffer and the riverbank texture bytes also matched exactly.

The existing tests, TypeScript check, and production build were used as the remaining gates. This is a readability revision, not a new physical calibration or a browser-based visual evaluation.

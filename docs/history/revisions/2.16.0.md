# World Forge 2.16.0 — Complete snapshots, local refinement and sediment transport

Complete physical worlds can be stored in browser-local IndexedDB and queried
through bounded readers. Regional refinement restores an existing world, transfers
its evolved state and rebuilds drainage without advancing geological history.
River sediment settling uses physical distance; floodplains, point bars, deltas
and alongshore transport participate in explicit material budgets.

See the [implementation record](../design/implementation-2.16.md) and
[measurements](../design/cloud-performance.md). The original sampled display tiles
were superseded by [fixed physical rendering in 2.17](2.17.0.md).
[2.16.2](2.16.2.md) changed saving to explicit manual promotion; current generation
does not automatically add a world to the saved library.

This summary records the imported prototype milestone; current behavior is
documented in the [architecture](../../architecture.md).

# Atlas 2.27.0 — readable wind and ocean-current animation

Wind and ocean-current trails could appear stationary for two separate reasons.
The display used short, one-pixel vector strokes with several moving heads
packed onto each stroke, making travel almost imperceptible. The render loop
also stopped flow animation while the optional cell grid or river network was
loading, even when the flow overlay itself was already ready.

## Changes

- Generate connected streamlines by resampling the saved seasonal vector field
  along each path. Interpolate nearby climate cells and use midpoint integration
  to follow turns rather than extending a single initial direction.
- Draw the trails as one indexed ribbon mesh with a consistent 2.4 CSS-pixel
  width, a brighter leading head, and a fading tail. Continuous path coordinates
  survive field samples, the map seam, and pole crossings.
- Anchor seeds geographically. Small camera pans retain overlapping seeds;
  density-scale changes can still replace paths. The existing accumulated clock
  preserves animation phase when packets are replaced.
- Test ocean membership along current paths. Refined water increases coast
  probes rather than automatically shortening every trail. Extremely fine
  regions use shorter safe steps and can terminate a trail when its fixed probe
  budget is reached; the renderer does not jump across unchecked coastlines.
- Animate resident flow overlays independently of grid and river loading. The
  existing GPU fence continues to limit in-flight frames. Pause, zero speed,
  visibility, and reduced-motion preferences retain their behavior.

This is a display correction, not a new climate simulation. Existing saved
worlds need no regeneration. Saving remains manual.

## Bounds and verification

Core work is limited to 256 paths, 48 integration segments per path, and the
requested packet budget (at most 8,192 segments). Ocean checks have a 512-probe
budget per path. Surface and climate-neighborhood caches each retain at most
4,096 entries. Rendering subdivides each path at most 64 times, with extra
pieces only where the map seam or pole requires a split. Animation changes GPU
uniforms and performs no storage queries or full-world reconstruction.

All 505 tests pass, along with TypeScript, changed-file formatting, and the
production build. Regression tests cover continuous curved paths, source
direction, coast barriers, seasonal cancellation, 2.6-million-cell equivalent
spacing, kilometre-scale water refinement, projection seams/poles, density
controls, and clock preservation.

Browser checks use Chromium/ANGLE SwiftShader in the cloud environment. Both
wind and currents are checked on the globe and flat map, including a saved
AETHER-2408 reference world with 251,559 surface cells and 40,962 climate cells.
The delayed-loading reproduction records zero animation-clock movement and zero
redraws before the fix; the corrected renderer continues advancing while those
independent requests remain pending. Paused frames remain identical.

These are functional checks and cloud software-rendering observations, not
